# 🤖 Machine Learning

> **Understanding Machine Learning from Mathematics → Algorithms → Code**

A collection of Machine Learning implementations, experiments, and practical
notebooks created while learning and exploring the fundamentals of Machine Learning.

The main focus of this repository is to understand **how Machine Learning
algorithms work internally**, rather than simply using ready-made functions.

## 🎯 Objective

The goal of this repository is to build a strong understanding of
Machine Learning fundamentals through **implementation and experimentation**.

Instead of treating Machine Learning models as black boxes, the focus is on
understanding the concepts behind them:
